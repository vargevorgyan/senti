# ApprovalPrompt

The popup Senti shows when an action needs the person's decision: which agent, what it wants to do in plain words, the exact command in mono, the rule that triggered it, and three choices (Block as primary, Allow once, Always allow as a quiet ghost button).

- Title in first person, terracotta-text; the app icon identifies Senti.
- Always show the rule, so people learn what Senti protects.
- Reserve it for irreversible or sensitive actions, to avoid approval fatigue.
