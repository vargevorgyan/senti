# Alert

How Senti barks: four states whose loudness matches the risk — Blocked (bark fill, cream text and warning sign), Ask (raised surface, terracotta-text border, title and icon), Allowed (sage-soft, sage-text) and Info (sand, ink).

- Blocked only when Senti actually stopped something; never for a question.
- Every alert has an icon and a first-person, plain-words title. Colour alone never carries the meaning.
- Name the file, folder or site in `code` style and say what would have happened.
- Ask alerts always offer a choice; Block is the primary (ink) button so the safe option is the easy one.
- No jokes or "Woof" inside alerts.
