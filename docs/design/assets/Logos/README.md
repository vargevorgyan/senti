# Logos

- `senti-app-icon.svg` — Primary logo. Cream dog on terracotta #C4623F, 28/130 corner radius. Dock, deck cover, avatars.
- `senti-mark.svg` — Terracotta dog on transparent, for cream and sand grounds.
- `senti-mark-cream.svg` — Cream dog on transparent, for espresso and terracotta grounds.
- `senti-bark.svg` — Secondary mark: shepherd-style profile, ears up, mouth open mid-bark with sage sound waves. For Blocked moments, "how it works" and the deck; alert, not scary.
- `senti-snarl.svg` — Secondary mark: same profile, mouth closed, lip curled to show teeth, wrinkled snout. The quiet warning before a bark: pairs with Ask alerts, while the bark pairs with Blocked. Both face left, made to sit in the bottom-right corner of a screen or slide.
