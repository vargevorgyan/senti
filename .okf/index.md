# Senti knowledge base

* [Development environment](dev-environment.md) - The team's primary dev Mac, installed and missing tools, accounts, and resource constraints observed on 2026-09-26.
* [Code guide (full build)](code-guide.md) - Map of the production code — engine (host-native), backend and admin panel (Docker), hooks/plugins, tests, e2e and demo scripts — and how to run each part.
